
# Sauvegarde Automatisée du Bastion

## Objectif

L'objectif est de mettre en place une solution de sauvegarde automatisée afin de protéger les données critiques du bastion d'administration.

La sauvegarde permet de limiter les risques de perte de données et de faciliter la restauration des services en cas d'incident.

## Mise en place de l'environnement

Un répertoire dédié aux sauvegardes a été créé sur le serveur Debian.

Création du répertoire :

```bash
sudo mkdir -p /srv/backups/bastion
```

Attribution des permissions :

```bash
sudo chown $USER:$USER /srv/backups/bastion
```

Vérification :

```bash
ls -ld /srv/backups/bastion
```

## Création du script de sauvegarde

Un script Bash a été développé afin d'automatiser les opérations de sauvegarde.

Création du fichier :

```bash
nano ~/Scripts/backup-bastion.sh
```

Attribution des droits d'exécution :

```bash
chmod +x ~/Scripts/backup-bastion.sh
```

## Éléments sauvegardés

Le script permet de sauvegarder :

* Les fichiers Docker Compose ;
* Les scripts d'administration ;
* Les configurations système ;
* La base de données MariaDB ;
* Les informations relatives aux conteneurs Docker.

Les données sont regroupées dans une archive compressée.

## Sauvegarde de la base MariaDB

La base de données utilisée par les services du bastion est exportée automatiquement.

L'outil utilisé est :

```bash
mysqldump
```

Cette opération permet de conserver les données nécessaires à une restauration ultérieure.

## Vérification du fonctionnement

Le script peut être exécuté manuellement afin de vérifier son bon fonctionnement.

Exécution du script :

```bash
~/Scripts/backup-bastion.sh
```

Contrôle des sauvegardes :

```bash
ls -lh /srv/backups/bastion
```

Consultation du journal :

```bash
cat /srv/backups/bastion/backup.log
```

## Automatisation avec Cron

Afin d'assurer une sauvegarde régulière, une tâche Cron a été configurée.

Modification de la table Cron :

```bash
crontab -e
```

Configuration :

```text
0 2 * * * /home/loic/Scripts/backup-bastion.sh
```

Vérification :

```bash
crontab -l
```

Cette tâche exécute automatiquement la sauvegarde chaque jour à 02h00.

## Vérification des sauvegardes

Les archives générées sont stockées dans le répertoire :

```text
/srv/backups/bastion
```

Contrôle des fichiers :

```bash
ls -lh /srv/backups/bastion
```

Vérification du journal :

```bash
cat /srv/backups/bastion/backup.log
```

La présence de nouvelles archives confirme le bon déroulement des sauvegardes.

## Procédure de restauration

Extraction d'une archive :

```bash
tar -xzf backup-bastion-AAAA-MM-JJ.tar.gz
```

Restauration d'une base MariaDB :

```bash
mysql -u utilisateur -p base_de_donnees < sauvegarde.sql
```

Cette procédure permet de récupérer rapidement les données sauvegardées.

## Apports de la sauvegarde

La mise en place de cette solution permet :

* La protection des données critiques ;
* L'automatisation des sauvegardes ;
* La réduction du risque de perte de données ;
* La simplification des opérations de restauration ;
* L'amélioration de la continuité de service.

## Résultat

Le bastion d'administration dispose désormais d'un système de sauvegarde automatisé permettant de protéger les configurations, les scripts et les données critiques nécessaires au fonctionnement de l'infrastructure.
