# Configuration de la Sauvegarde Automatisée

## Objectif

Afin de garantir la disponibilité des services et la protection des données critiques du bastion d'administration, une solution de sauvegarde automatisée a été mise en place.

Cette sauvegarde permet de conserver les configurations essentielles ainsi que les données nécessaires à une restauration rapide en cas d'incident.

---

## Présentation de la sauvegarde

La stratégie de sauvegarde repose sur un script Bash exécuté automatiquement par Cron.

Les sauvegardes sont archivées au format compressé afin de limiter l'espace disque utilisé.

La solution permet :

* la sauvegarde des fichiers Docker Compose ;
* la sauvegarde des scripts d'administration ;
* la sauvegarde de la base de données MariaDB ;
* l'archivage des configurations système ;
* la conservation d'un historique de sauvegardes.

---

## Préparation de l'environnement

Création du répertoire destiné aux sauvegardes :

```bash
sudo mkdir -p /srv/backups/bastion
```

Attribution des permissions :

```bash
sudo chown $USER:$USER /srv/backups/bastion
```

Vérification :

```bash
ls -ld /srv/backups/bastion
```

---

## Création du script de sauvegarde

Création du fichier :

```bash
nano ~/Scripts/backup-bastion.sh
```

Ajout du script de sauvegarde puis enregistrement du fichier.

Rendre le script exécutable :

```bash
chmod +x ~/Scripts/backup-bastion.sh
```

---

## Test de fonctionnement

Exécution manuelle :

```bash
~/Scripts/backup-bastion.sh
```

Vérification du contenu du répertoire :

```bash
ls -lh /srv/backups/bastion
```

Le système génère alors une archive compressée contenant les données sauvegardées.

---

## Sauvegarde de la base MariaDB

La base de données utilisée par les services conteneurisés est exportée automatiquement grâce à l'utilitaire :

```bash
mysqldump
```

Cette opération permet de conserver :

* les tables ;
* les utilisateurs ;
* les données de configuration ;
* les paramètres applicatifs.

Le fichier SQL généré est ensuite intégré à l'archive de sauvegarde.

---

## Planification automatique avec Cron

Ouverture de la table Cron :

```bash
crontab -e
```

Ajout de la tâche planifiée :

```bash
0 2 * * * /home/loic/Scripts/backup-bastion.sh
```

Cette configuration déclenche une sauvegarde quotidienne à 02h00.

Vérification :

```bash
crontab -l
```

---

## Vérification des sauvegardes

Consultation du journal :

```bash
cat /srv/backups/bastion/backup.log
```

Contrôle des archives :

```bash
ls -lh /srv/backups/bastion
```

La présence régulière de nouvelles archives confirme le bon fonctionnement du système.

---

## Procédure de restauration

Extraction d'une archive :

```bash
tar -xzf backup-bastion-AAAA-MM-JJ.tar.gz
```

Les fichiers restaurés peuvent ensuite être replacés dans leur emplacement d'origine.

Pour une base MariaDB :

```bash
mysql -u utilisateur -p base_de_donnees < sauvegarde.sql
```

Cette procédure permet une remise en service rapide des composants sauvegardés.

---

## Avantages

La mise en place de cette sauvegarde permet :

* la protection des données critiques ;
* l'automatisation des opérations de sauvegarde ;
* la réduction du risque de perte de données ;
* la simplification des opérations de restauration ;
* l'amélioration de la continuité de service.

---

## Sécurité

Les sauvegardes sont stockées sur le serveur bastion dans un répertoire dédié.

L'accès est limité aux administrateurs du système.

Les opérations sont journalisées afin de faciliter le suivi des sauvegardes réalisées.

---

## Résultat

Les configurations du bastion, les scripts d'administration et la base de données MariaDB sont désormais sauvegardés automatiquement.

Cette solution renforce la résilience de l'infrastructure et constitue une bonne pratique d'administration système dans un environnement professionnel.
