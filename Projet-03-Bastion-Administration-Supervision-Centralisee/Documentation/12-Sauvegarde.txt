# Sauvegarde Automatisée du Bastion

## Objectif

L'objectif est de mettre en place une sauvegarde automatisée du serveur bastion afin de protéger les données critiques et faciliter la restauration des services en cas d'incident.

La sauvegarde permet de limiter les risques de perte de données et d'améliorer la continuité de service.

## Solution mise en œuvre

Une tâche automatisée a été configurée afin d'effectuer régulièrement une sauvegarde des éléments essentiels de l'infrastructure.

Les sauvegardes sont générées sous forme d'archives compressées et stockées dans un répertoire dédié.

## Éléments sauvegardés

Les composants suivants sont inclus dans la sauvegarde :

* Fichiers Docker Compose ;
* Scripts d'administration ;
* Configuration du bastion ;
* Base de données MariaDB ;
* Informations relatives aux conteneurs Docker.

## Sauvegarde de la base de données

La base de données MariaDB utilisée par les services du bastion est exportée automatiquement.

Outil utilisé :

```text
mysqldump
```

L'export est intégré à l'archive de sauvegarde afin de permettre une restauration ultérieure.

## Automatisation avec Cron

La sauvegarde est exécutée automatiquement grâce au planificateur de tâches Linux.

Configuration :

```text
0 2 * * * /home/loic/Scripts/backup-bastion.sh
```

Cette tâche déclenche une sauvegarde quotidienne à 02h00.

## Vérification des sauvegardes

Les archives générées sont stockées dans le répertoire :

```text
/srv/backups/bastion
```

Les journaux permettent de vérifier le bon déroulement des opérations.

Consultation du journal :

```bash
cat /srv/backups/bastion/backup.log
```

## Procédure de restauration

Une archive peut être extraite afin de récupérer les fichiers sauvegardés.

Extraction :

```bash
tar -xzf backup-bastion-AAAA-MM-JJ.tar.gz
```

Pour une base MariaDB :

```bash
mysql -u utilisateur -p base_de_donnees < sauvegarde.sql
```

## Apports de la sauvegarde

La mise en place de cette solution permet :

* La protection des données critiques ;
* L'automatisation des sauvegardes ;
* La réduction du risque de perte de données ;
* La simplification des opérations de restauration ;
* L'amélioration de la continuité de service.

## Résultat

Le bastion d'administration dispose désormais d'un système de sauvegarde automatisé permettant de protéger les configurations, les scripts et les données nécessaires au fonctionnement de l'infrastructure.
