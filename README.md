\# TSSR Portfolio



Portfolio technique réalisé dans le cadre de la préparation du titre professionnel :



\*\*Technicien Supérieur Systèmes et Réseaux (TSSR)\*\*



\## Objectif



Ce dépôt regroupe plusieurs projets d'infrastructure systèmes et réseaux réalisés en environnement de laboratoire.



\## Projets



\### Projet 01 - Infrastructure AD sécurisée Griffon



Déploiement d'une infrastructure Active Directory sous Windows Server 2022, avec DNS, GPO, modèle AGDLP et durcissement inspiré des bonnes pratiques ANSSI/CIS.



\### Projet 02 - Infrastructure multisites



Mise en place d'une architecture réseau interconnectée par VPN site-à-site.



\### Projet 03 - Linux Samba



Déploiement d'un serveur Linux Debian avec services réseau et partages Samba.



\### Projet 04 - Supervision



Mise en place d'une solution de supervision avec Prometheus et Grafana.



\## Compétences



\- Windows Server 2022

\- Active Directory

\- DNS

\- GPO

\- PowerShell

\- Linux Debian

\- Samba

\- pfSense

\- VPN

\- Supervision

\- Sécurité système
