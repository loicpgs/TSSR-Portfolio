
# Organisation de l'entreprise Griffon

## Présentation générale

Griffon est une entreprise fictive spécialisée dans le développement, l'intégration et le maintien en condition opérationnelle de systèmes destinés aux secteurs de l'aérospatial et de la défense.

Cette organisation a été créée afin de reproduire un environnement d'entreprise réaliste dans le cadre du déploiement d'une infrastructure Active Directory sécurisée sous Windows Server 2022.

L'effectif simulé est composé d'environ cinquante collaborateurs répartis entre plusieurs services métiers.

## Organigramme fonctionnel

| Service             | Mission                                           |
| ------------------- | ------------------------------------------------- |
| Direction           | Pilotage stratégique et gouvernance               |
| Ressources Humaines | Gestion du personnel et des recrutements          |
| Finance             | Gestion comptable, budgétaire et achats           |
| Bureau d'Études     | Conception et développement des systèmes          |
| Production          | Intégration, assemblage et validation             |
| Informatique        | Administration systèmes, réseaux et cybersécurité |

## Objectifs de l'organisation Active Directory

L'organisation retenue doit permettre :

* la séparation des responsabilités ;
* l'application de stratégies de groupe ciblées ;
* la mise en œuvre du modèle AGDLP ;
* la gestion centralisée des identités ;
* l'application des bonnes pratiques Microsoft, CIS et ANSSI.

## Correspondance avec l'Active Directory

Chaque service dispose :

* d'une unité d'organisation dédiée ;
* d'un groupe global de sécurité ;
* d'un groupe local de domaine associé aux ressources ;
* de règles d'accès spécifiques.

Cette approche facilite l'administration quotidienne tout en limitant les risques liés à une mauvaise attribution des droits.
