# Tests de Connectivité

## Test LAN

Vérification de la communication avec le routeur :

```bash
ping 192.168.50.1
```

## Test Internet

Vérification de l'accès Internet :

```bash
ping 8.8.8.8
```

## Test DNS

Vérification de la résolution de noms :

```bash
ping google.com
```

## Résultats

Les trois tests sont concluants :

- communication LAN fonctionnelle ;
- accès Internet opérationnel ;
- résolution DNS correcte.
