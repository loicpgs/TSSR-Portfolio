# Déploiement d’une Infrastructure Réseau Sécurisée avec Détection d’Intrusion et Supervision

---

# 1. Contexte et Objectifs

Dans le cadre de ma formation de Technicien Supérieur Systèmes et Réseaux (TSSR), j'ai réalisé une infrastructure réseau sécurisée sous Linux Debian.

L'objectif de ce projet est de mettre en œuvre :

* Un routeur Linux assurant la communication entre un réseau local et Internet ;
* Un mécanisme de translation d'adresses (NAT) ;
* Un pare-feu assurant la protection du réseau ;
* Un système de détection d'intrusion (IDS) basé sur Suricata ;
* Une solution de supervision et de centralisation des logs avec Loki et Grafana.

---

# 2. Architecture de l'Infrastructure

L'infrastructure est composée des éléments suivants :

* Routeur Debian
* Réseau LAN : 192.168.50.0/24
* Réseau WAN (Internet)
* Poste client Windows
* IDS Suricata
* Loki
* Promtail
* Grafana

## 10.4 Création de Règles Personnalisées

### Détection ICMP

```bash
alert icmp any any -> any any (msg:"PING DETECTED"; sid:1000001; rev:1;)
```

### Détection Scan SYN

```bash
alert tcp any any -> any any (flags:S; msg:"SYN SCAN DETECTED"; sid:1000002; rev:1;)
```
