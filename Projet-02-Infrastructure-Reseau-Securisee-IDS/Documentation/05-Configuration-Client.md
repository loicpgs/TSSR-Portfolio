# Configuration du Poste Client

## Paramètres réseau

Le poste client Windows est configuré manuellement avec :

| Paramètre | Valeur |
|------------|------------|
| Adresse IP | 192.168.50.10 |
| Masque | 255.255.255.0 |
| Passerelle | 192.168.50.1 |
| DNS | 8.8.8.8 |

## Objectif

Permettre au client :

- de communiquer avec le routeur ;
- d'accéder à Internet ;
- de résoudre les noms DNS.
