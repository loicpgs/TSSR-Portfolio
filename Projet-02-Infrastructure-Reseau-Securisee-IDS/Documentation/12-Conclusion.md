# Conclusion

Ce projet a permis de mettre en œuvre une infrastructure réseau complète intégrant :

- routage IP ;
- NAT ;
- firewall ;
- détection d'intrusion ;
- supervision centralisée.

## Compétences mobilisées

- Administration Linux Debian
- Réseau TCP/IP
- Routage
- NAT
- Firewall iptables
- IDS Suricata
- Analyse de logs
- Sécurité réseau
- Loki
- Grafana
- Supervision

## Bilan

L'intégration de Suricata, Loki et Grafana permet de se rapprocher d'un environnement SOC (Security Operations Center) en offrant une visibilité en temps réel sur les événements de sécurité du réseau.
